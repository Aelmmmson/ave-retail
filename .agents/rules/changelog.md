# Rule: Mandatory CHANGELOG Maintenance

- **Requirement**: Whenever any code modifications, additions, features, or bug fixes are introduced to the repository, you **MUST** update `CHANGELOG.md`.
- **Format**: Follow [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) standard format with clear version numbers, release dates, and sections (`Added`, `Changed`, `Fixed`, `Security`).
- **Scope**: Document both backend API changes, database schema updates, frontend UI features, and documentation additions.
